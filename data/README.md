# data/

Generated by `build_scorecard.py`. Not brand data you edit by hand.

- **scorecard.json** - `{"pages": [...], "stats": {...}}`. Performance + category + priority per page.
- **audit.json** - `{"audit_rows": [...], "money_pages": [...], "blog_pages": [...]}`. Strategy per page plus the blog slugs and money pages used for cannibalization and internal linking.

Both are read by `lookup.py`, `cannibal.py`, and the workflow. Regenerate them by running
`python build_scorecard.py` from the project root after your GSC/inventory exports change.
These files are gitignored by default (they are outputs, and may contain site data).
